# LogGT

Implementation of LogGT: Cross-system log anomaly detection via heterogeneous graph feature and transfer learning.

## 📖 Introduction

This project implements **LogGT**, a cross-system log anomaly detection method based on **heterogeneous graph features** and **transfer learning**.

By constructing log data into a **heterogeneous graph** and leveraging the **HGT (Heterogeneous Graph Transformer)** to extract deep structural features, LogGT achieves log anomaly detection in cross-system scenarios.

## 📂 Project Structure

Data-Thunderbird.ipynb is used to generate heterogeneous graphs, while HGT_Thunderbird. ipynb is used as network_fithout_time.
